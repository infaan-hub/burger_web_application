CTA
Example Master Prompt

Create a premium cinematic scrollytelling website in React that feels like an interactive commercial rather than a traditional webpage. Use React Bits components, Framer Motion, Anime.js, Lenis smooth scrolling, and optionally GSAP ScrollTrigger or React Three Fiber for scroll-driven storytelling. Build the experience as one continuous animation where every section transitions seamlessly without abrupt page changes. As the user scrolls, animation progress is tied directly to scroll position, with smooth easing, inertia, parallax, staggered reveals, dynamic lighting, floating particles, and depth effects.

The hero begins with a gourmet burger exploded into separate floating ingredients (top bun, lettuce, tomato, onion, cheese, beef patty, sauces, bottom bun). Each ingredient gently rotates, floats, and reacts with realistic motion while steam and subtle particles create a premium atmosphere. With each scroll, the ingredients gradually align and assemble into a finished burger while the camera subtly zooms, pans, and rotates around it. Throughout the journey, headlines, descriptions, statistics, feature cards, pricing, testimonials, and call-to-action buttons appear through elegant text reveals and motion synchronized to the burger assembly. Backgrounds, colors, gradients, lighting, and UI elements transition continuously so the experience feels like a cinematic product launch rather than a sequence of independent sections.

**Design the interface with world-class UI/UX using glassmorphism, premium typography, responsive layouts, accessible interactions, magnetic buttons, animated gradients, spotlight effects, BlurText, SplitText, GlareCard, PixelTrail, and other React Bits components. Ensure 60 FPS performance, lazy loading where appropriate, and a fully responsive experience across desktop, tablet, and mobile. The result should feel comparable to Apple's product pages or a luxury brand advertisement, where scrolling tells a compelling visual story and every animation has purpose.
